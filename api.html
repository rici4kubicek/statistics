API reference

This section documents the public C API of the library. The documentation is extracted from header comments and grouped using Doxygen.

Overview

  • Core structures and functions live in the statistics_core group.

  • Main header file: include/statistics.h.

Mathematical definition

The functions work on all \(N\) samples of the ring buffer (\(N\) = samplesCnt, the capacity), \(x_1 \dots x_N\):

\[\mathrm{Max} = \max_i x_i, \qquad \mathrm{Min} = \min_i x_i, \qquad \bar{x} = \frac{1}{N} \sum_{i=1}^{N} x_i\]
\[s^2 = \frac{1}{N-1} \sum_{i=1}^{N} \left(x_i - \bar{x}\right)^2 \quad (N \ge 2), \qquad s = \sqrt{s^2}\]

Integer types return fixed-point values scaled by 1000. \(R(\cdot)\) is rounding half away from zero:

\[\mathrm{Mean} = R\!\left(1000\,\bar{x}\right), \qquad \mathrm{Variance} = V \approx R\!\left(1000\,s^2\right), \qquad \mathrm{Stdev} = \left\lfloor \sqrt{1000\,V} \right\rfloor \approx 1000\,s\]

\(V\) is computed with Welford’s online algorithm in 64-bit integers (intermediate divisions truncate, the final division rounds). Float types return \(\bar{x}\), \(s^2\) and \(s\) directly, with \(s^2 = \left(\sum x_i^2 - (\sum x_i)^2 / N\right) / (N-1)\).

Exponential smoothing filter

  • Structures and functions live in the exponential_smoothing_core group.

  • Header file: include/exponential_smoothing.h.

Mathematical definition

With the smoothing factor \(N\) (factor), the accumulator \(B\) holds the filtered value scaled by \(N\):

\[B_0 = N\,y_0, \qquad B_k = B_{k-1} - \frac{B_{k-1}}{N} + x_k, \qquad y_k = \frac{B_k}{N}\]

which is the exponential moving average with \(\alpha = 1/N\):

\[y_k = y_{k-1} + \frac{1}{N}\left(x_k - y_{k-1}\right)\]

  • factor – Smoothing factor, must be > 0 (larger = smoother, slower to react).

Linear regression

  • Structures and functions live in the linear_regression_core group.

  • Header file: include/linear_regression.h.

Mathematical definition

Each point updates running means over \(n\) points, \(\bar{u}_n = \bar{u}_{n-1} + (u_n - \bar{u}_{n-1}) / n\) for \(u \in \{x, x^2, y, y^2, xy\}\). From them:

\[\sigma_x^2 = \overline{x^2} - \bar{x}^2, \qquad \sigma_y^2 = \overline{y^2} - \bar{y}^2, \qquad \sigma_{xy} = \overline{xy} - \bar{x}\,\bar{y}\]

The result (\(n \ge 3\)) of the line \(y = m x + b\):

\[m = \frac{\sigma_{xy}}{\sigma_x^2} \;(0 \text{ if } \sigma_x^2 = 0), \qquad b = \bar{y} - m\,\bar{x}, \qquad r = \frac{\sigma_{xy}}{\sigma_x \sigma_y} \;(1 \text{ if } \sigma_x^2 = 0 \text{ or } \sigma_y^2 = 0)\]
\[\mathrm{jitter} = \sqrt{\frac{S_{yy} - m^2 S_{xx}}{n - 2}}, \qquad S_{xx} = n\,\sigma_x^2, \quad S_{yy} = n\,\sigma_y^2\]

Slope uncertainty with the coverage factor \(k\) and the Y resolution \(\Delta_y\), \(u_{\mathrm{res}}^2 = \Delta_y^2 / 3\):

\[\begin{split}U_m = \begin{cases} \infty & n \le 1 \\ k \sqrt{u_{\mathrm{res}}^2 / \overline{x^2}} & n = 2 \\ k \sqrt{\left(\overline{y^2} / (n - 2) + u_{\mathrm{res}}^2\right) / \overline{x^2}} & n \ge 3 \end{cases}\end{split}\]

Integer math helpers

  • Structures and functions live in the statistics_int_math group.

  • Header file: include/statistics_int_math.h.

Mathematical definition

\(R(\cdot)\) is rounding half away from zero, \(R(q) = \mathrm{sgn}(q) \left\lfloor |q| + \tfrac{1}{2} \right\rfloor\).

\[\mathrm{FloorShift}(v, s) = \left\lfloor \frac{v}{2^{s}} \right\rfloor \;(s > 63 \text{ acts as } 63), \qquad \mathrm{DivRound}(v, d) = R\!\left(\frac{v}{d}\right) \;(d > 0), \qquad \mathrm{Isqrt64}(v) = \left\lfloor \sqrt{v} \right\rfloor\]
\[\mathrm{Clamp}(v, lo, hi) = \min\!\left(\max(v, lo), hi\right) \quad (lo \le hi)\]

Linear range mapping from \([x_0, x_1]\) (inMin, inMax) to \([y_0, y_1]\) (outMin, outMax), without output clamping:

\[\begin{split}\mathrm{Map\_I32}(x) = \begin{cases} y_0 & x_0 = x_1 \\ \mathrm{sat}_{32}\!\left(y_0 + R\!\left(\dfrac{(x - x_0)(y_1 - y_0)}{x_1 - x_0}\right)\right) & \text{otherwise} \end{cases}\end{split}\]

\(\mathrm{sat}_{32}\) limits to \([-2^{31}, 2^{31} - 1]\). StatFloat_Clamp uses the same clamp definition. StatFloat_Map is the same mapping without \(R\) and without saturation.

int64_t StatInt_FloorShift(int64_t value, unsigned shift)

Arithmetic shift right with floor rounding: floor(value / 2^shift).

Unlike value >> shift, the result does not depend on the implementation-defined right shift of negative values. Example: StatInt_FloorShift(-1, 4) == -1, StatInt_FloorShift(-16, 4) == -1, StatInt_FloorShift(-17, 4) == -2.

Parameters:

  • value – Value to shift (full int64_t range).

  • shift – Shift count; values above 63 behave like 63 (result 0 for value >= 0, -1 for value < 0).

Returns:

floor(value / 2^shift).

int32_t StatInt_Map_I32(int32_t value, int32_t inMin, int32_t inMax, int32_t outMin, int32_t outMax)

Linear range mapping (Arduino map() style) with rounding.

Returns outMin + (value - inMin) * (outMax - outMin) / (inMax - inMin), with the division rounded half away from zero (see StatInt_DivRound).

  • Reversed ranges are allowed (inMin > inMax and/or outMin > outMax).

  • inMin == inMax returns outMin.

  • The output is NOT clamped to [outMin, outMax]: a value outside the input range is extrapolated. Combine with StatInt_Clamp_I32 when needed.

  • A result outside the int32_t range saturates to INT32_MIN / INT32_MAX.

  • No overflow for any int32_t arguments (64-bit intermediates; at most two unsigned 64-bit divisions per call).

Parameters:

  • value – Input value.

  • inMin – Input value mapped to outMin.

  • inMax – Input value mapped to outMax.

  • outMin – Output for inMin.

  • outMax – Output for inMax.

Returns:

Mapped value.

Fixed-point exponential smoothing filter

  • Structures and functions live in the exponential_smoothing_i32_core group.

  • Header file: include/exponential_smoothing_i32.h.

Mathematical definition

The accumulator \(A\) holds the filtered value in Q\(F\) fixed point (\(F\) = frac, \(s\) = shift). Inputs are first clamped to the representable range, \(c(x) = \mathrm{Clamp}\left(x, \lfloor -2^{31} / 2^F \rfloor, \lfloor (2^{31} - 1) / 2^F \rfloor\right)\):

\[A_0 = 2^{F} c(y_0), \qquad A_k = A_{k-1} + \left\lfloor \frac{2^{F} c(x_k) - A_{k-1}}{2^{s}} \right\rfloor\]
\[\mathrm{GetValue} = \left\lfloor \frac{A_k + 2^{F-1}}{2^{F}} \right\rfloor \;(F > 0), \qquad \mathrm{GetValue} = A_k \;(F = 0)\]

This is the exponential moving average \(y_k = y_{k-1} + \alpha (x_k - y_{k-1})\) with \(\alpha = 2^{-s}\).

void ExponentialSmoothingI32_Init(ExponentialSmoothingI32 *filter, unsigned shift, unsigned frac, int32_t initValue)

Initialize the filter.

An invalid parameter (shift > EXPONENTIAL_SMOOTHING_I32_SHIFT_MAX, frac > EXPONENTIAL_SMOOTHING_I32_FRAC_MAX) leaves the filter in an invalid state where ExponentialSmoothingI32_Process and ExponentialSmoothingI32_Reset are no-ops and ExponentialSmoothingI32_GetValue returns 0.

Parameters:

  • filter – [out] Pointer to the filter instance to initialize.

  • shift – alpha = 1 / 2^shift, 0 = no smoothing.

  • frac – Fractional bits of the accumulator, usually EXPONENTIAL_SMOOTHING_I32_FRAC_DEFAULT.

  • initValue – Initial filtered value.

Integer sliding-window regression

  • Structures and functions live in the window_regression_i32_core group.

  • Header file: include/window_regression_i32.h.

Mathematical definition

The window holds \(n\) samples \((t_i, y_i)\) per channel, with \(t_N\), \(y_N\) the newest one. Ages are wrap-safe uint32 differences, limited to the oldest age \(a_{\max}\), and scaled by the smallest \(s\) with \(\lfloor a_{\max} / 2^s \rfloor < 2^{13}\):

\[a_i = (t_N - t_i) \bmod 2^{32}, \qquad x_i = -\left\lfloor \frac{a_i}{2^{s}} \right\rfloor, \qquad d_i = \mathrm{Clamp}\!\left(y_i - y_N, -2^{20}, 2^{20}\right)\]
\[S_x = \sum x_i, \quad S_{xx} = \sum x_i^2, \quad S_d = \sum d_i, \quad S_{xd} = \sum x_i d_i\]

The fit needs \(n \ge \max(\mathrm{minCount}, 2)\) and \(n S_{xx} - S_x^2 > 0\). Slope \(m\) in Q16 per x unit, clamped to \(\pm m_{\max}\) when \(m_{\max}\) (slopeMaxQ16) is not 0:

\[m = \mathrm{Clamp}\!\left(R\!\left(\frac{2^{16}\,(n S_{xd} - S_x S_d)}{2^{s}\,(n S_{xx} - S_x^2)}\right), -m_{\max}, m_{\max}\right)\]

Level \(L\) in Q16 at \(t_N\): the line goes through the centroid \((\bar{t}, \bar{y})\), also when \(m\) is clamped:

\[L = 2^{16} y_N + R\!\left(\frac{2^{16} S_d + m \sum a_i}{n}\right) \;\approx\; 2^{16}\left(\bar{y} + \frac{m}{2^{16}} \left(t_N - \bar{t}\right)\right)\]

Evaluation at \(t\), with the signed difference \(\Delta = (t - t_N) \bmod 2^{32}\) taken in \([-2^{31}, 2^{31})\):

\[\mathrm{Evaluate}(t) = \mathrm{sat}_{32}\!\left(\left\lfloor \frac{L + m\,\Delta + 2^{15}}{2^{16}} \right\rfloor\right)\]

bool WindowRegressionI32_Fit(WindowRegressionI32 *reg, uint16_t minCount, uint32_t slopeMaxQ16)

Fit a least-squares line per channel over the stored samples.

On success the result is in WindowRegressionI32::lines and WindowRegressionI32::fitX is the newest x.

Parameters:

  • reg – Pointer to the instance.

  • minCount – Minimum stored samples for a result (values < 2 act as 2).

  • slopeMaxQ16 – |slope| limit in Q16 per x unit, 0 = no limit. A clamped line still goes through the centroid of the samples.

Returns:

true on success; false when fewer than minCount samples are stored or all stored x are equal (no result, fitted = false).

bool WindowRegressionI32_Evaluate(const WindowRegressionI32 *reg, uint8_t channel, uint32_t x, int32_t *value)

Value of the last fitted line of a channel at x.

x is taken relative to WindowRegressionI32::fitX as a wrap-safe signed difference, so it must lie within +-2^31 of it. The result is rounded half up and saturates to the int32_t range.

Parameters:

  • reg – Pointer to the instance.

  • channel – Channel index.

  • x – x to evaluate the line at.

  • value – [out] Line value at x.

Returns:

true on success; false if there is no fit result, channel is out of range or a pointer is NULL (value is not written).
